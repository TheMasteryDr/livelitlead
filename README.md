# Live Lit Lead 🔥

> **We are ON FIRE. We are BUILT DIFFERENT. We are SENT TO INFLUENCE.**

A modern, high-energy spiritual teaching & discipleship platform designed to ignite faith, build unshakeable character, and empower Kingdom leadership.

---

## ✨ Features

- **Weekly Spiritual Teachings:** Stream and explore weekly video teachings on YouTube with integrated playback modals.
- **Dynamic Filtering & Search:** Search teachings by keyword, scripture, speaker, and topics (Faith, Identity, Kingdom Authority, Leadership, etc.).
- **The Three Core Pillars:**
  - **Live Lit:** Living on fire for God with radical conviction and daily spiritual passion.
  - **Build Lit:** Constructing unshakeable biblical foundations, spiritual discipline, and character.
  - **Lead Lit:** Influencing culture, marketplace, and community with Kingdom excellence.
- **Admin Dashboard:** In-browser teaching management to add, update, and manage videos.
- **Responsive & Modern Design:** Tailored with typography, glassmorphism, smooth animations, and dark mode aesthetics.

---

## 🚀 Getting Started

### Local Development

1. Clone this repository:
   ```bash
   git clone <REPO_URL>
   cd livelitlead
   ```

2. Start the local server:
   ```bash
   node server.js
   ```

3. Open your browser and navigate to:
   ```
   http://127.0.0.1:3000
   ```
